Triple Flexion — Vận Động Ba Khớp Gập

By Fault Tolerant Tennis · Biomechanical Reference (2023) · Original Article ↗

Triple flexion (gập ba khớp) là cơ chế tạo power trong tennis. Bài viết này giải thích 3 khớp, cách chúng hoạt động, và tại sao quan trọng.

Triple Flexion Là Gì?

Triple flexion = gập đồng thời 3 khớp trong giai đoạn nạp (loading phase):

  1. 1. Ankle (Cổ Chân): Dorsiflexion — cổ chân gập về phía ống.
  2. 2. Knee (Đầu Gối): Knee flexion — đầu gối gập.
  3. 3. Hip (Hông): Hip flexion — hông gập.

Triple flexion là SSC (stretch-shortening cycle) mạnh nhất. Cơ bắp + gân tích trữ năng lượng đàn hồi → giải phóng bùng nổ khi duỗi (extension).

5 Lợi Ích Của Triple Flexion

  1. 1. Power Tối Đa: GRF + elastic energy → power lớn.
  2. 2. Speed (Tốc Độ): Reaction nhanh hơn với cơ đã nạp.
  3. 3. Stability: 3 khớp cùng gập → cơ thể ổn định.
  4. 4. Agility (Linh Hoạt): Từ tư thế này → di chuyển bất kỳ hướng.
  5. 5. Injury Prevention: SSC đúng → giảm chấn thương.

3 Yếu Tố Kỹ Thuật

  1. 1. Deep Knee Bend: Gập gối ~45-60°.
  2. 2. Hip Hinge: Hông gập, lưng giữ thẳng.
  3. 3. Ankle Dorsiflexion: Cổ chân gập về phía ống ~15-20°.

5 Tình Huống Dùng Triple Flexion

  1. 1. Ready Position: Triple flexion nhẹ (chuẩn bị).
  2. 2. Split-Step: Triple flexion sâu (nạp cho bật).
  3. 3. Forehand Power: Triple flexion khi load → extension khi swing.
  4. 4. Serve: Triple flexion khi toss → extension khi đánh.
  5. 5. Volley: Triple flexion khi prepare → extension khi volley.

5 Cách Tập Triple Flexion

  1. 1. Wall Sit: 30-60s, lưng dựa tường.
  2. 2. Squat: 3 set 10 reps.
  3. 3. Box Jump: 3 set 5-8 reps (explosive extension).
  4. 4. Lateral Lunge: 3 set 10 mỗi bên (hip + ankle mobility).
  5. 5. Sport-Specific: Tennis drill với triple flexion.

Mô Hình 2026: SSC Foundation

Trong khung 2026, triple flexion = SSC foundation (nền tảng SSC): nạp năng lượng đàn hồi → giải phóng bùng nổ. Đây là yếu tố cơ bản của mọi power movement trong tennis.
