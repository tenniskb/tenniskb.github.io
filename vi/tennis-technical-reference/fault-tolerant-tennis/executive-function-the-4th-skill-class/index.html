Chức Năng Điều Hành — Lớp Kỹ Năng Thứ 4

By Fault Tolerant Tennis · Psychological Reference (2023) · Original Article ↗

Trong tennis, có 4 lớp kỹ năng cần phát triển: Technical (kỹ thuật), Tactical (chiến thuật), Physical (thể chất), và Executive Function (chức năng điều hành). Lớp thứ 4 — executive function — thường bị bỏ qua nhưng quyết định hiệu suất dưới áp lực.

4 Lớp Kỹ Năng

  1. 1. Technical Skills (Kỹ Thuật): Forehand, backhand, serve, volley. Lớp này dễ đo lường nhất.
  2. 2. Tactical Skills (Chiến Thuật): Đọc đối thủ, chọn cú đánh, xây dựng điểm. Lớp này khó hơn nhưng vẫn có thể học.
  3. 3. Physical Skills (Thể Chất): Tốc độ, sức mạnh, sức bền, agility. Lớp này cần thời gian dài.
  4. 4. Executive Function (Chức Năng Điều Hành): Khả năng quyết định, tập trung, điều phối cảm xúc, kiểm soát impulse dưới áp lực. Lớp này khó nhất nhưng quan trọng nhất.

Executive Function Là Gì?

Executive function = nhóm kỹ năng nhận thức cao cấp điều khiển hành vi:

  • Working Memory (Bộ Nhớ Làm Việc): Giữ và xử lý thông tin real-time (đối thủ vừa đánh gì? điểm số bao nhiêu?)
  • Cognitive Flexibility (Linh Hoạt Nhận Thức): Chuyển đổi chiến thuật real-time (đối thủ thích nghi → bạn phải đổi)
  • Inhibitory Control (Kiểm Soát Ức Chế): Không bốc đồng (đừng đập vợt, đừng cú đánh liều khi tức giận)
  • Planning (Lập Kế Hoạch): Suy nghĩ trước (match plan, cú đánh tiếp theo)
  • Decision-Making (Ra Quyết Định): Chọn cú đánh tốt nhất trong <500ms

3 Cách Huấn Luyện Executive Function

  1. 1. Pressure Simulation (Mô Phỏng Áp Lực): Tiebreak mỗi buổi tập. Đếm điểm. Hậu quả cho mất điểm.
  2. 2. Decision Drills: HLV đưa ra tình huống: "Đối thủ serve vào T, bạn return thế nào?" Bạn phải quyết định trong 5 giây.
  3. 3. Reflection Journal (Nhật Ký Phản Án): Sau mỗi trận, viết: "3 quyết định tốt nhất, 3 quyết định tệ nhất, lý do tại sao".

Huấn Luyện: Drill "Executive Function Tennis"

  1. Tiebreak mỗi buổi (15 phút): Áp lực thực tế. Mục tiêu: thực thi match plan dưới áp lực.
  2. Decision drills (10 phút): HLV hỏi "đối thủ serve X, bạn đánh Y?" Bạn trả lời 5 giây.
  3. Reflection journal (10 phút sau trận): Ghi 3 quyết định tốt, 3 quyết định tệ.

Mô Hình 2026: Executive Fault Tolerance

Trong khung 2026, executive function = cognitive fault tolerance (chịu lỗi nhận thức): khả năng quyết định đúng dưới áp lực, kiểm soát cảm xúc, chuyển đổi linh hoạt. Đây là kỹ năng phân biệt ATP top 50 vs top 200.
