# Bài viết 077: Duy Trì Chức Năng Điều Hành Vào Điều Kiện Set 5

> **CUE CHUYÊN GIA:** Set 5 = **Executive Function (EF) stress test** 3-5 giờ. PFC mỏi → Working memory 0, Inhibitory control 0, Cognitive flexibility 0, Decision making 0. Train "EF Endurance" = vô địch. Không chỉ thể lực — não lực.

## 1. Tóm Tắt Điều Hành & Ý Định Thể Thao

**Executive Function (Chức năng điều hành - EF)** là tập hợp các quá trình nhận thức bậc cao do **Dorsolateral PFC (DLPFC)** điều phối: (1) **Working Memory** (Giữ & thao tác thông tin), (2) **Inhibitory Control** (Ức chế đáp ứng tự động/sai), (3) **Cognitive Flexibility** (Chuyển đổi task set), (4) **Planning/Decision Making** (Kế hoạch, quyết định), (5) **Attentional Control** (Kiểm soát chú ý). Trong trận 5 set (3-5 giờ), **PFC fatigue** tích lũy do: Glucose depletion, Dopamine/Norepinephrine depletion, Cortisol accumulation, Adenosine accumulation, Metabolic waste. **EF Degradation** = Original sin của late-match collapse: UE tăng, Decision making sai, Pattern recognition mất, Emotional control mất. Bài viết này định nghĩa **EF Endurance**, ngưỡng degradation, giao thức "EF Conditioning", và ma trận chẩn đoán "Late-Match EF Collapse".

Ý định thể thao ba khía cạnh: thứ nhất, làm **EF thành hệ thống có endurance có thể train** — không chỉ "trí tuệ". Thứ hai, định nghĩa **ngưỡng "EF Critical Zone"**: Set 3-4 (90-120 phút) bắt đầu degradation, Set 5 (2.5-4h) = critical. Thứ ba, cung cấp **bộ can thiệp "EF Fuel + EF Training + EF Protection"**.

## 2. Nền Tảng Thần Kinh - Nhận Thức

### 2.1 5 Thành Phần EF & Tennis Mapping

| Thành Phần EF | Vùng Não | Tennis Function | Degradation Sign (Late Match) |
|---------------|----------|-----------------|-------------------------------|
| **1. Working Memory (WM)** | DLPFC | Giữ pattern đối thủ, Scoreline, Tactics, 3 heuristic rules | Quên pattern, Quên score, Quên heuristic |
| **2. Inhibitory Control** | Right IFG, Pre-SMA | Chặn swing sai, Chặn emotional reaction, Chặn "hero shot" | Swing vội, Hero shot, Emotional outburst |
| **3. Cognitive Flexibility** | DLPFC, ACC, BG | Pivot plan A→B, Adjust to conditions | Cứng nhắc, Stuck in failing pattern |
| **4. Planning/Decision** | DLPFC, OFC | Serve placement, Return strategy, Shot selection | Poor shot selection, Reactive not proactive |
| **5. Attentional Control** | DLPFC, FEF, PPC | Focus on relevant cues, Filter noise | Distracted by crowd, Score, Fatigue feel |

## 3. Thực Hành Kỹ Thuật Từng Bước

### Giai Đoạn 1: EF Baseline & Monitoring (Cơ Sở & Giám Sát EF)

**Bài tập 1: "EF Battery Baseline" (Pin EF Cơ Sở - Fresh)"
- **WM:** N-back 2-back (accuracy, RT), Digit span forward/backward.
- **Inhibitory:** Stroop test (Color-Word), Go/No-Go, Stop-signal task.
- **Flexibility:** Task-switching (Color/Shape), Trail Making Test B-A.
- **Decision:** Iowa Gambling Task / Tennis scenario decision task.
- **Attention:** Continuous Performance Test (CPT), Antisaccade.
- **Lưu:** Baseline scores. **Re-test Set 3, Set 5** (nếu có thể) hoặc post-match.

**Bài tập 2: "In-Match EF Proxy" (Proxy EF Trong Trận - Không Cần Máy)"
| Proxy | Cách Đánh Giá | Ngưỡng Cảnh Báo |
|-------|---------------|-----------------|
| **WM** | Hỏi VĐV: "Pattern 3 lần cuối ĐT serve?", "Score hiện tại?", "3 heuristic rules?" | Sai >1 = WM fail |
| **Inhibitory** | UE count, Hero shot count, Emotional outburst | UE >3/set, Hero shot >2 = Inhibit fail |
| **Flexibility** | Pivot success rate (Bài 076), Pattern change compliance | Pivot fail >2 = Flex fail |
| **Decision** | Shot selection quality (Video review), Serve placement variance | Poor selection >30% = Decision fail |
| **Attention** | Gaze control (Eye-tracker), Between-point routine compliance | Routine skip >2 = Attention fail |

### Giai Đoạn 2: EF Fueling Protocol (Giao Thức Nạp Nhiên Liệu EF)

**Nutrition Timeline (Dinh Dưỡng Theo Thời Gian):**
| Thời Điểm | Can Thiệp | Liều Lượng | Cơ Chế |
|-----------|-----------|------------|--------|
| **Pre-match (3h)** | Low GI Carb + Protein | 2-3g/kg carb, 0.5g/kg protein | Liver glycogen max, Stable glucose |
| **Pre-match (1h)** | Light carb + Caffeine + Tyrosine | 1g/kg carb, 3-6mg/kg caffeine, 1-2g tyrosine | Gastric emptying, DA/NE precursor |
| **Set 1-2 (Changeover)** | Carb gel + Electrolyte | 20-25g carb/changeover | Maintain blood glucose |

| **Set 4-5** | Gel + BCAA + Electrolyte + **Caffeine top-up** | 25g carb, 5g BCAA, 100mg caffeine | Central fatigue delay, PFC fuel |

### Giai Đoạn 3: EF Training (Huấn Luyện Endurance EF)

**Bài tập 3: "Extended Cognitive-Motor Session" (Phiên Kết Hợp Nhận Thức - Vận Động Kéo Dài)"
- Mô phỏng trận 3-4 set: **3-4 giờ liên tục** tênis + nhận thức.
- Mỗi changeover: **EF Mini-test** (30s): 2-back 10 trial + Stroop 10 trial + Task-switch 10 trial.
- Điểm: Tennis performance + EF test accuracy.
- **Target:** EF accuracy drop <15% từ Set 1 → Set 4.

**Bài tập 4: "Dual-Task Endurance" (Nhiệm Vụ Kép Kéo Dài)"
- Rally/Point play liên tục 60-90 phút.
- Đồng thời: **Auditory n-back** (nghe số, nhớ 2-back) / **Mental arithmetic**.
- Đo: Tennis performance (UE%, consistency) + Cognitive accuracy theo thời gian.
- **Target:** Tennis performance stable, Cognitive accuracy >80% tại 90'.

**Bài tập 5: "EF Protection Drills" (Drill Bảo Vệ EF)"
- **Micro-recovery (Bài 061)** giữa MỖI ĐIỂM: 25s protocol bảo vệ PFC glucose/DA.
- **Heuristic Offload (Bài 053):** 3 rules max → WM load <3 chunks.
- **External Focus (Bài 045):** "Target + Spin" → Bypass PFC motor control.
- **Routine Automation (Bài 047):** Pre-point ritual → PFC offload.

### Giai Đoạn 4: Set 5 Specific Protocol (Giao Thức Đặc Biệt Set 5)

**Nếu vào Set 5 (hoặc 10-point tiebreak quyết định):**
```
IMMEDIATE (Changeover trước Set 5):
1. NUTRITION: Glucose gel 25g + Caffeine 100mg + BCAA 5g + Electrolyte
2. PHYSICAL: Cold towel face/neck 60s (Vagal, PFC cooling) → Light stretch
3. COGNITIVE: 4-1-6-1 breath × 4 (Vagal reset) → Visualize 2 điểm tới (MI)
4. STRATEGIC: "CHỈ 3 RULES" viết trên tay/giấy:
   Rule 1: Serve % >70% (Body/T)
   Rule 2: Return deep middle (Zero UE)
   Rule 3: Rally >4 shots → Attack short only
5. EMOTIONAL: "Set 5 = Opportunity. Opponent cũng mỏi. Ai giữ EF tốt hơn = Thắng."
```

**In-Set 5 (Mỗi changeover):**
- Glucose mouth rinse 10s (không nuốt) → Immediate PFC boost.
- 4-1-6-1 × 2.
- Review 3 rules compliance.
- Body language: Upright, Chin up, Shoulders back.
