# ART-573: Return Against Second Serves — Aggression and Targeting

## Executive Summary

The second serve is the returner's best opportunity to take control of the point. By attacking second serves aggressively, returners can put pressure on the server and create break opportunities. This article covers the techniques and tactics for effective second serve returning.

## Why Second Serves Are Attackable

### Slower Pace
- Second serves are typically 20-30% slower than first serves
- This gives the returner more time to react and set up
- The slower pace allows for a more aggressive swing

### More Predictable
- Second serves often follow predictable patterns
- The returner can anticipate where the serve will go
- The returner can position themselves optimally

### Higher Margin for Error
- The slower pace means the returner can take more risks
- A missed aggressive return on a second serve is less costly than on a fast first serve
- The potential reward (breaking serve) justifies the risk

## Positioning for Second Serves

### Move Inside the Baseline
- Stand 1-3 feet inside the baseline to return second serves
- This takes time away from the server
- Allows you to hit down on the ball for a better angle

### Adjust Based on the Server
- If the server hits second serves to your backhand, start slightly toward the backhand
- If the server hits second serves wide, start slightly wider
- If the server hits second serves body, stay in the center

## Techniques for Returning Second Serves

### The Drive Return
- Use a full swing to drive the ball
- Step into the return with the drive step
- Target the server's weaker side
- Aim deep to keep the server back

### The Inside-Out Return
- Hit the return from your forehand side with an inside-out swing
- This creates a sharp angle to the server's backhand
- Effective against servers with weaker backhands

### The Down-the-Line Return
- Hit the return down the line to the server's forehand or backhand
- This changes the direction of play and catches the server off-guard
- Effective when the server is expecting a crosscourt return

## Tactical Options

### Target the Server's Weaker Side
- Direct returns to the server's weaker stroke (usually the backhand)
- This neutralizes their ability to attack after serving
- Forces them to hit from their weaker side

### Return Deep
- Aim for the back third of the court
- Deep returns prevent the server from attacking
- Keep the server back and force them to hit from behind the baseline

### Return Short
- Drop the return short to force the server to run forward
- Effective against servers who stay back
- Creates a weak reply that you can attack

## Diagnostic & Training Matrix

| Observation | Failure | Result | Corrective Strategy |
| :--- | :--- | :--- | :--- |
| Not attacking second serves | Passive returning | Missed break opportunities | Aggressive return drills; second serve attack practice |
| Standing too deep for second serves | Not taking time away | Server has time to set up | Move inside baseline; practice forward positioning |
| Returns go to server's strength | Not targeting weaker side | Easy returns for server | Targeting drills; practice directing returns |
| Over-swinging on second serves | Trying too hard | Errors | Controlled swing drills; placement practice |

## Practical Application: "The Second Serve Attack Drill"

Have a partner hit only second serves while you practice moving inside the baseline to return, using a full swing to drive the ball, targeting the server's weaker side, and aiming deep to keep the server back. Track your success rate and aim for 60%+ of second serve returns landing in the court.
