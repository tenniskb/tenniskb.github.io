## Status legend

Each file's frontmatter includes:

- `synthesis_status: done` — the book has been incorporated into one or more gap reports.
- `synthesis_target: reports/tier-X-...` — which tier report cites it.
- `artifact_ref: artifacts/...` — the actual report path.
- `relevance` — 0.0–1.0 score for how strongly the book supports the gap thesis.
