# Technical Analysis — How the Strokes Themselves Changed

## What This Section Is

The Training Programs above let you train a legend's signature attribute. This section is one level more zoomed-out: it looks at how the strokes themselves evolved across eras and across body types, using multiple players as data points rather than one program as a template.

| Analysis | Focus |

| [Forehand Evolution: From Classic to Modern](forehand-evolution.md) | Grip, stance, and swing-path changes from the 1970s eastern-grip flat forehand to today's semi-western/western topspin game, and what equipment had to do with it |

## How to Use These

Read the matching stroke chapter in the [Handbook](../../handbook/index.md) first for the underlying mechanics this site actually teaches, then use these analyses to see how far technique has stretched across different body types and eras — and where the outer edges of "correct" technique actually sit.
