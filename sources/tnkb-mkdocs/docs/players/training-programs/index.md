# Training Programs — Modeled on the Greats

## What This Section Is

The player profiles elsewhere in this section explain *why* Federer or Sinner play the way they do. This section is the operational counterpart: structured, multi-week training programs that let you actually train the specific attribute a legendary player was known for, whether that's Agassi's return of serve, Sampras's serve, or Nadal's physical engine.

Each program runs 8-12 weeks, is organized into phases with explicit weekly goals, and closes with a metrics section so progress is measurable rather than a feeling. None of these are meant to be followed blindly — read the matching stroke or system page elsewhere on this site for the underlying mechanics first, then use the program to build the physical and tactical habits around it.

## How to Use These Programs

Pick the program that matches the stroke or attribute you most want to develop, run it 3-4 sessions per week for its full duration, and track the weekly metrics honestly rather than skipping to the next phase early. Cross-reference the [System section](../../system/index.md) for the underlying biomechanics and control-theory framing behind each program's drills.
