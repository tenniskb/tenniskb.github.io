# ART-129: Match Analytics — Turning Data into Decisions

## Executive Summary
The modern game runs on numbers: serve percentages, rally lengths, error maps. This article establishes a practical analytics framework for players and coaches — what to track, how to interpret it, and how it feeds back into training priorities across the 5 Pillars.

## The Analytics Framework

### 1. The Core Metrics (Per Match)
| Metric | What It Tells You | Elite Benchmark |
| :--- | :--- | :--- |
| First-serve % | Rhythm + risk calibration | 60-65% |
| First-serve points won | Serve + first-ball combo quality | > 70% |
| Second-serve points won | Kick quality + defense stability | > 50% |
| Return games won | Return + rally design | > 30% |
| Unforced error map | Weak zones by wing/direction | UE < winners |
| Rally-length profile | Where you win points | Balance across 0-4 / 5-8 / 9+ |
| Break-point save rate | Clutch execution | > 60% |

### 2. The Shot Quality Score
Grade every shot 1-4 live:
*   **4 = Weapon:** Forces opponent error/defense.
*   **3 = Neutral-plus:** Depth + margin.
*   **2 = Neutral:** Playable but passive.
*   **1 = Liability:** Sets up opponent's attack.

**Rule of thumb:** Elite matches average shot quality ≥ 2.8; errors cluster at moments of declining average.

### 3. Video Analysis Protocol (Weekly)
1.  **First pass (no tools):** Watch the match as a story. Note momentum shifts.
2.  **Second pass (logging):** Tag every point: serve location, return quality, first-ball direction, rally length, error type.
3.  **Third pass (pillar mapping):** Assign each error to a pillar root cause (I-V).
4.  **Output:** 3 findings + 1 training priority. More than that is noise.

### 4. Data → Practice Conversion
| Finding | Pillar | Training Action |
| :--- | :--- | :--- |
| 2nd-serve points won < 40% | III + IV | Kick-serve volume + Serve+1 pattern reps |
| Errors on backhand DTL | III | Backhand mechanics block with DTL constraint targets |
| Losing 9+ shot rallies | V | Oxidative interval emphasis shift |
| Break points lost on passive returns | II + IV | Pressure-scenario return simulations |

## Practical Application: The "Dashboard Feedback Loop"
Track → Find the bleeding → Train the specific pillar → Re-measure next match. Analytics without a training conversion step is just trivia.
