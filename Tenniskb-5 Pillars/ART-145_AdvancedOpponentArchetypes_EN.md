# ART-145: Advanced Opponent Archetypes — The Scouting Dossier

## Executive Summary
Article 123 introduced the six archetypes. This article deepens the dossier: specific data points to collect, video tagging protocols, and match-plan construction for each archetype. Scouting is not guessing; it is data-driven pattern recognition.

## The Scouting Data Protocol (Per Opponent)

### 1. Serve Metrics (Min 20 serves observed)
*   **1st Serve % / Placement % (Wide/Body/T).**
*   **1st Serve Speed Avg / Max.**
*   **2nd Serve Type % (Kick/Slice/Flat) & Placement.**
*   **Serve +1 Pattern:** Forehand % / Backhand % / Serve & Volley %.

### 2. Return Metrics
*   **Return Depth % (Short / Mid / Deep).**
*   **Return Direction vs. Serve Location (Cross / Down Line / Block).**
*   **Aggression Index:** % of returns hit with intent to offense vs. neutralize.

### 3. Rally Metrics (Min 30 rallies)
*   **Rally Length Distribution:** 0-4 / 5-8 / 9+ shots.
*   **Shot Tolerance:** Errors forced vs. Unforced per wing.
*   **Wing Preference:** % Forehand / Backhand run-around.
*   **Net Frequency:** % points ended at net.

### 4. Pressure Metrics (Break Points, Set Points, 30-40, 40-30)
*   **Serve Direction Tendency.**
*   **Return Aggression Drop-off.**
*   **Pattern Simplification:** Does tactic shrink to "safe"?

## Archetype-Specific Counter-Intelligence

### 1. The Power Baseliner
*   **Key Data:** 1st Serve % < 55%? Forehand Error Threshold (shots tolerated)?
*   **Plan:** Make them hit 1 extra ball. Target BH depth. Serve wide to FH to open court for return.

### 2. The Counterpuncher
*   **Key Data:** Winner/UE Ratio. Net Points Won %.
*   **Plan:** Patience with margin. Attack 2nd serve. Bring them in with drop shots (test volley).

### 3. The Serve-and-Volleyer
*   **Key Data:** 1st Serve % at 30-40. Volley Win % (FH vs BH volley).
*   **Plan:** Return low at feet. Lob early to back them off. Pass DTL (they shade cross).

### 4. The All-Court Artist
*   **Key Data:** Drop Shot Frequency / Success Rate. Slice BH Depth.
*   **Plan:** Heavy, deep, center court. Rush 2nd serve. No rhythm.

### 5. The Grind-Returner
*   **Key Data:** Return Depth Avg. Break Point Return Aggression.
*   **Plan:** Serve variety (Body/Slider). S&V surprise. Drop shot to draw them up.

### 6. The Big Server
*   **Key Data:** 2nd Serve Speed/Spin. Return Games Played (experience).
*   **Plan:** Block return deep middle. Extend rallies. Mental discipline on BP.

## The Match Plan Document (1-Page)
*   **Header:** Opponent Name / Ranking / Surface / Conditions.
*   **3 Tactical Keys:** (e.g., "1. Return Deep CC. 2. Serve Wide +1 FH. 3. No Drop Shots vs this opponent.")
*   **3 Mental Keys:** (e.g., "1. Breathe on BP. 2. Reset strings. 3. Next Ball.")
*   **Emergency Adjustments:** "If down 0-3: More 1st serves. If up 3-0: Keep foot on gas."

## Practical Application: "The Dossier"
A match plan without data is a wish. A match plan with data is a strategy. Build the dossier. Execute the plan. Adjust only when data demands it.
