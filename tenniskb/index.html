    The CORE Chain¶

    Q → V → ROOT → F → P → T → SSC → 8 → 45° → BRAKE → PULSE → JIN

    Quiet Eye → Vestibular → Rooting → Fascia → Proprioception → Tensegrity → SSC → Figure-8 → 45° Plane → Brake → Pulse → Jin

    Every variable is a link. Break one, and the chain fails. Master all twelve, and the stroke becomes inevitable.
